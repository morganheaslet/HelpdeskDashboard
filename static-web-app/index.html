What's live today

ConnectWise ManageTicket volume, status, priority, owner, source, and backlog age — pulled live on every refresh. Covers Managed Services, Technical Services, Alerts, Security Services, and Dispatch.
DialpadCall volume, answer rate, talk time, and per-tech phone stats — pulled live via Dialpad's Stats API. Today's Snapshot shows the current day; the Phones tab shows a rolling 8-week history, refreshed incrementally (only the current in-progress week re-pulls every run; older weeks are fetched once as they roll into the window).

What's still manual

NinjaOneDevice counts, patch status, and RMM-driven alert closures aren't pulled yet; alert ticket data comes from ConnectWise, but NinjaOne-side detail (e.g. which policy fired) is not yet joined in.
CSAT / SLA / utilization legacy figuresThese were pulled manually from BrightGauge in the prior workflow and have no live source yet — see the Work In Progress tab.
