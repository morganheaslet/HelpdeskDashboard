What's live today

ConnectWise ManageTicket volume, status, priority, owner, source, and backlog age — pulled directly via the ConnectWise API at report generation. Covers the Managed Services, Technical Services, and Alerts boards.

What's still manual

DialpadCall volume, answer rate, talk time, per-tech phone stats. No connector available yet — the Phones tab reproduces the last manually-built export.
NinjaOneDevice counts, patch status, and RMM-driven alert closures aren't pulled yet; alert ticket data comes from ConnectWise, but NinjaOne-side detail (e.g. which policy fired) is not yet joined in.
CSAT / SLA / utilization legacy figuresThese were pulled manually from BrightGauge in the prior workflow. Carried over as-is (see Phones & Historical tab) pending a live source.

Suggested next steps to fully automate

1Add a Dialpad connector (or scheduled CSV export) so call metrics refresh alongside ConnectWise data instead of being pasted in by hand each week.
2Wire in NinjaOne for device counts and patch/alert origin, joined to ConnectWise tickets by client and asset.
3Move the "current period" tech leaderboard and backlog snapshot onto a scheduled pull (e.g. every Monday morning) so this page is regenerated automatically rather than on request.
4The legacy report's SLA/CSAT/utilization figures were pulled manually from BrightGauge — once those metrics have a live source (ConnectWise SLA fields, or a BrightGauge connector), they can be folded into the live tabs instead of carried over as-is.
